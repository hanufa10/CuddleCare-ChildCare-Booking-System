# CuddleCare-ChildCare-Booking-System

## 🌟 Project Overview
The **Child-care Booking System** is a web-based platform designed to connect **parents/guardians** with **childcare providers** (daycares, schools, babysitters).  
It enables parents to **register children, book childcare services, and track real-time updates** on their child’s activities, health, and academic progress. Providers can manage their services, communicate with parents, and maintain records. Admins oversee the entire system.

---

## 🎯 Goals & Objectives
- Provide a user-friendly platform for parents to manage childcare needs.  
- Enable providers to manage children’s records, schedules, and bookings.  
- Ensure secure communication between parents and providers.  
- Maintain reliable medical, attendance, and academic progress records.  
- Support notifications and reminders for events and milestones.

---

## 👥 User Roles
1. **Parent/Guardian**  
   - Register/login  
   - Add child profiles (personal, health, academic info)  
   - Book childcare services  
   - View attendance, progress, and updates  
   - Communicate with providers  

2. **Childcare Provider**  
   - Register childcare center/company  
   - Manage children’s attendance, progress, and medical records  
   - View and accept bookings  
   - Send updates & notifications to parents  

3. **Admin**  
   - Manage parents and providers  
   - Approve/reject childcare providers  
   - Monitor bookings and records  
   - Generate system reports

---

## 🛠️ Tech Stack
- **Frontend:** React, HTML, CSS, JavaScript  
- **Backend:** PHP, MySQL  
- **Database:** MySQL  
- **Version Control:** Git & GitHub  
- **Hosting:** Localhost/XAMPP initially, deploy later  

---

## ⚙️ Features
- **Authentication:** Secure login/signup for all roles  
- **Parent Dashboard:** Child profiles, bookings, updates, communication  
- **Provider Dashboard:** Attendance, schedules, activities, reports  
- **Admin Dashboard:** Manage users, providers, system data  
- **Booking System:** Parents book available services  
- **Medical & Progress Tracking:** Record children’s health, milestones, and academic progress  
- **Notifications:** Real-time updates via dashboard  
- **Communication:** Secure messaging/contact form

## 🚀 Getting Started
1. **Clone the repository:**  
   git clone https://github.com/your-username/childcare-system.git
2. **Install dependencies:**
    Frontend: npm install (for React)
    Backend: setup XAMPP with MySQL and PHP
3. **Run the project:**
    Start backend server (localhost/XAMPP)
    Start frontend React server: npm start
4. **Access**
    Open http://localhost:3000 (frontend) and http://localhost/phpmyadmin (database)
